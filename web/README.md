# เว็บ + LINE OA "ไร่ไม่เผา"

| หน้า | ใช้ทำอะไร |
|---|---|
| `/` | หน้าแรก + โมเดล 3D: จุดชี้ชิ้นส่วน (กดดูว่าทำอะไร/มีไว้ทำไม), ปุ่ม **ดู flow การทำงาน** (เลือก A/B/C), X-ray, แยกชิ้น |
| `/present` | **โหมดพรีเซนต์** สไลด์เต็มจอ 9 หน้า (← → เปลี่ยนสไลด์, F = เต็มจอ) ใช้โมเดลและตัวเลขชุดเดียวกับระบบจริง |
| `/liff` | หน้าเกษตรกรใน LINE: ยินยอม PDPA → ราคา/คำนวณ → แจ้งขาย (นำมาเอง หรือ **เรียกรถไปรับ**) → รับ QR → ติดตามรถ → สิทธิ์ |
| `/liff/driver` (`/driver`) | หน้าคนขับแบบ Grab: สมัคร → งานใกล้ฉัน → รับงาน → นำทาง/โทร → รับของแล้ว → แสดง QR ที่ตู้ → รายได้ |
| `/prices` | ตารางราคารับซื้อ + เครื่องคิดเงิน |
| `/kiosk` | หน้าจอสัมผัสหน้าตู้ (เปิดบนแท็บเล็ต): สแกน QR → ความชื้น → โหมด → แปรรูป → ใบรับของเข้า LINE |
| `/dashboard` | ผลกระทบ, คิววันนี้, สถานะตู้, แจ้งช่าง |
| `/privacy` | นโยบายความเป็นส่วนตัว |

- API อยู่ใน `api/` (Vercel Functions) ดูรายละเอียดใน `../docs/SRS.md` หัวข้อ 6
- **ตัวเลขธุรกิจทั้งหมด** (ราคา ผลผลิต ความชื้นสูงสุด ค่า PM2.5) อยู่ที่ `shared/rules.js` ไฟล์เดียว
- ข้อมูลจำลองของ Dashboard อยู่ที่ `src/lib/seed.js`
- **2 ภาษา (ไทย/EN):** ปุ่มสลับภาษาอยู่ที่แถบบนทุกหน้า ข้อความเขียนแบบ `t('ไทย', 'English')` ส่วนชื่อโหมด/วัตถุดิบดึงจากฟิลด์ `en` ใน `shared/rules.js` (ข้อความ LINE ยังเป็นภาษาไทย)
- **คำอธิบายชิ้นส่วนและขั้นตอน flow** แก้ได้ที่ `src/data/parts.js` ส่วนตำแหน่งจุดสร้างจาก Blender (`src/data/hotspots.json`)

```bash
npm install
npm run dev     # http://localhost:5173 (API ทำงานในเครื่องได้เลย ไม่ต้องใช้ Vercel CLI)
npm test        # ทดสอบ API ทั้งหมด (จำลอง LINE)
npm run build
node scripts/make-richmenu.mjs   # สร้างรูป rich menu ใหม่ → ../docs/line/richmenu.png
```

Deploy และเชื่อม LINE: ดู [`../docs/LINE_SETUP.md`](../docs/LINE_SETUP.md)

## 1. โครงการนี้เกี่ยวกับอะไร (ในหนึ่งย่อหน้า)
ปี 2569 ไทยมีพื้นที่เผาทางการเกษตร **26.0 ล้านไร่** สูงสุดเป็นประวัติการณ์ ภาคเหนือเผามากที่สุด **16.17 ล้านไร่** (ที่มา: GISTDA) เกษตรกรเผาเพราะ**เป็นวิธีที่ถูกและเร็วที่สุด** ต้นทุนจึงไปตกอยู่กับสังคมในรูปฝุ่น PM2.5 และโรคทางเดินหายใจ "ไร่ไม่เผา" ทำให้เศษพืช**มีราคา** ตั้งตู้แปรรูป 3 in 1 ไว้ใน**สถานีประจำหมู่บ้าน** รับซื้อเศษพืชแล้วแปรรูปเป็น**อาหารสัตว์ แท่งเชื้อเพลิง และวัสดุทำปุ๋ย/เพาะเห็ด** ทุกขั้นตอนสั่งงานและจ่ายเงินผ่าน LINE มีระบบเรียกรถคนในหมู่บ้านไปรับถึงไร่แบบ Grab

## 2. ปัญหา → ทางออก
| ปัญหา | ทางออกของไร่ไม่เผา |
|---|---|
| เผาถูกที่สุด ทางเลือกอื่นต้องเสียเงิน (จ้างไถกลบ) | **รับซื้อ ~1 บาท/กก.** การไม่เผากลายเป็นรายได้ |
| เศษพืชเบาแต่กินที่ ขนเองลำบาก | **รถคนในหมู่บ้านไปรับถึงไร่** ค่ารถไม่เกิน 30% ของยอดขาย |
| ไม่มีคนรับซื้อ ไม่รู้ว่าจะแปรรูปเป็นอะไร | **ตู้ 3 in 1** ทำได้ 3 สินค้า เลือกตามความต้องการของตลาด |
| ชั่งน้ำหนักไม่โปร่งใส | ตาชั่ง กล้อง และเครื่องวัดความชื้นในตู้ **ส่งใบรับของเข้า LINE อัตโนมัติ** |
| วัดผลกระทบไม่ได้ | Dashboard นับ กก. ที่ไม่ถูกเผา, PM2.5 ที่ลดได้, รายได้เกษตรกรจากทุกงาน |

## 3. ทำงานยังไง (5 ขั้นตอน)
1. **เรียกรถผ่าน LINE**: เกษตรกรแจ้งชนิดเศษพืช น้ำหนักโดยประมาณ แล้วเลือกขนมาเองหรือเรียกรถ (เรียกรถได้เมื่อ ≥ 300 กก. หรือเต็มคันรถ)
2. **รถในหมู่บ้านไปรับ**: คนขับที่สมัครไว้ได้แจ้งงาน กดรับงานแบบใครก่อนได้ก่อน มีรถให้เลือก 2 แบบ (กระบะติดคอก / รถอีแต๋น)
3. **ชั่ง ถ่ายรูป วัดความชื้นที่สถานี**: สแกน QR ของล็อตที่หน้าตู้ ความชื้นเกิน 20% ไม่รับ ฝากตากที่ลานของสถานีก่อนได้
4. **แปรรูปที่ตู้**: เลือกโหมด A / B / C
5. **เกษตรกรเลือก**: **ขายให้ไร่ไม่เผา** (ได้เงิน) / **ฝากขาย** / **รับกลับไปใช้เองหรือขายเอง** (จ่ายค่าบริการแปรรูป) แล้วได้ใบรับของเข้า LINE

### สถานีประจำหมู่บ้าน (~2 ไร่ ทำงานคล้ายปั๊มน้ำมัน)
ประกอบด้วย 8 ส่วน: ① ตาชั่งพื้นที่รับของ ② ลานตากที่มีหลังคา ③ อาคารที่เปิดตั้งตู้ ④ หลังคาแผงโซลาร์ ⑤ โกดังแยกล็อต ⑥ ร้านค้าและสำนักงาน ⑦ ถังดับเพลิง ⑧ ที่จอดรถ · **การขยาย:** เริ่มด้วยตู้ 3 in 1 หนึ่งตู้ต่อหมู่บ้าน แล้วเพิ่มตู้เมื่อมีวัตถุดิบมากขึ้น

## 4. ตู้ทำงานยังไง
**ขนาด** กว้าง 85 × สูง 180 × ลึก 60 ซม. (ประมาณตู้กดน้ำ) จัดชั้นตามแรงโน้มถ่วง วัตถุดิบไหลจากบนลงล่าง

| ความสูง | ส่วนประกอบ | หน้าที่ |
|---|---|---|
| 140–180 ซม. | ช่องป้อน + ฝามีสวิตช์ตัดไฟ, ตะแกรงกันมือ, แม่เหล็กดักเศษเหล็ก, เซนเซอร์ความชื้น, หน้าจอสัมผัส/สแกน QR/กล้อง | รับของ ตรวจความชื้น ยืนยันตัวตนล็อต |
| 100–140 ซม. | เครื่องสับ hammer mill ~3 kW + ตะแกรง 2 ขนาด | สับเศษพืชให้ละเอียด |
| 85–100 ซม. | ลิ้นสลับทาง (มอเตอร์) | ส่งวัตถุดิบไปช่อง A / B / C ตามโหมด |
| 30–85 ซม. | ซ้าย **A** flat die อัดเม็ด (2 ขนาด) · กลาง **C** ช่องตรง · ขวา **B** screw press + ขดลวดความร้อน + ตัดท่อน | แปรรูป |
| 0–30 ซม. | ถาดรับ 3 ช่อง + ตาชั่งใต้ถาด | ชั่งผลผลิต คำนวณอัตราได้คืน |
| ด้านหลัง | พัดลมดูดฝุ่น + ถุงเก็บฝุ่น, ตู้ควบคุมไฟฟ้า, ช่องระบายความร้อน | ความปลอดภัย ฝุ่น ความร้อน |

| โหมด | สินค้า | อัตราได้คืน* | เวลา/100 กก.* |
|---|---|---|---|
| **A อัดเม็ด** (เขียว) | อาหารสัตว์อัดเม็ด / เชื้อเพลิงอัดเม็ด | 85% | ~60 นาที |
| **B อัดแท่ง** (ส้ม) | แท่งเชื้อเพลิง (แทนถ่าน/ฟืน) | 80% | ~75 นาที (+อุ่นเครื่อง 15 นาที) |
| **C สับ** (ฟ้า) | วัสดุคลุมดิน / เพาะเห็ด / ทำปุ๋ยหมัก | 90% บนบอร์ด · 95% ในเว็บ | ~15 นาที |

\* ค่าประมาณ · หมายเหตุ: อัตราได้คืนโหมด C บนบอร์ดเขียน 90% แต่ในเว็บ (`rules.js`) ตั้งไว้ 95% ควรเลือกใช้ค่าเดียวกัน

**ข้อจำกัดที่รู้แล้ว:** ทำได้ทีละโหมด (แก้ด้วยระบบคิว) · ถ้าจะเปลี่ยนจากเชื้อเพลิงไปทำอาหารสัตว์ ต้องเดินเครื่องเปล่าไล่ของเก่าก่อน · ถ้าเครื่องสับเสีย ทั้งตู้หยุด (มีใบมีดสำรอง + แจ้งช่างอัตโนมัติทุก 200 ชั่วโมงทำงาน)

## 5. การใช้ตู้ (สำหรับพนักงานหน้าตู้)
1. สแกน QR ของล็อตจาก LINE ของเกษตรกร (ล็อตที่แปรรูปแล้ว สแกนซ้ำไม่ได้)
2. ตู้ชั่งน้ำหนัก ถ่ายรูป และวัดความชื้นอัตโนมัติ: ≤ 15% ราคาเต็ม · 15–20% ลด 10% · > 20% ตู้ไม่รับ
3. เลือกโหมด A / B / C (ถ้าทำอัดเม็ด ให้เลือกแม่พิมพ์อาหารสัตว์หรือเชื้อเพลิงด้วย)
4. ยืนยันการทำความสะอาด/ไล่ของเก่า แล้วกดเริ่ม · มี**ปุ่มหยุดฉุกเฉิน**สีแดงหน้าตู้
5. แปรรูปเสร็จ ตู้ชั่งผลผลิตในถาด แล้ว**ส่งใบรับของเข้า LINE** พร้อมยอดเงิน
6. ระบบแจ้งช่างเมื่อครบรอบบำรุงรักษา

ลองใช้งานจำลองได้ที่ `/kiosk` บนเว็บต้นแบบ

## 6. Business model
**ลูกค้า 2 ฝั่ง (platform สองด้าน):** ฝั่งต้นน้ำคือเกษตรกรผู้มีเศษพืช ฝั่งปลายน้ำคือผู้รับซื้อสินค้า เช่น ฟาร์มเห็ด สหกรณ์โคนม ฟาร์มสัตว์ โรงอบ/โรงงานที่ใช้หม้อไอน้ำ และร้านค้าชุมชน

### รายได้ (Revenue streams)
| ทาง | รายละเอียด |
|---|---|
| ① ขายสินค้าที่แปรรูปแล้ว | ส่วนต่างระหว่างราคารับซื้อเศษพืช (~1 ฿/กก.) กับราคาขายอาหารสัตว์ แท่งเชื้อเพลิง และวัสดุปุ๋ย/เพาะเห็ด **(รายได้หลัก)** |
| ② ค่าบริการแปรรูป | เกษตรกรที่รับกลับไปใช้เอง: A 1.20 · B 1.50 · C 0.40 ฿/กก. |
| ③ ค่าแพลตฟอร์มรถ | 10% ของค่ารถ (คนขับได้ 90%) |
| ④ อนาคต | สปอนเซอร์ CSR / งบลดฝุ่นจากหน่วยงานท้องถิ่น / คาร์บอนเครดิต |

### ต้นทุนหลัก
ค่าซื้อเศษพืช · ค่าไฟ (ลดด้วยหลังคาโซลาร์) · ค่าแรงพนักงานหน้าตู้ · ค่าบำรุงรักษา (ใบมีด แม่พิมพ์) · **กองทุนอุดหนุนค่ารถ** · ค่าตู้และสถานี (ลงทุนครั้งแรก)

### ราคาที่ใช้ในต้นแบบ
| รายการ | ราคา |
|---|---|
| รับซื้อเศษพืช (฿/กก.) | ข้าวโพด 1.00 · ฟาง/ตอซังข้าว 1.00 · กิ่งไม้ผล 1.00 · ใบอ้อย 0.80 |
| ความชื้น | ≤ 15% ราคาเต็ม · 15–20% ลด 10% · > 20% ไม่รับ |
| ค่ารถ | 50 ฿ + 10 ฿/กม. (รวมไปกลับ) + 0.10 ฿/กก. · รัศมี 10 กม. |
| เพดานค่ารถ (เฉพาะขายให้บริษัท) | เกษตรกรจ่าย ≤ 30% ของยอดขาย ส่วนเกินกองทุนช่วยจ่าย · คนขับได้ 90% ของค่ารถเต็มเสมอ · รับกลับไปเอง: จ่ายค่ารถเต็ม |

**ตัวอย่าง 1:** ขายซังข้าวโพดแห้ง 1,000 กก. ห่าง 6 กม. → ยอดขาย 1,000 ฿ · ค่ารถ 50 + 60 + 100 = 210 ฿ (ไม่เกิน 30%) → **เกษตรกรได้สุทธิ 790 ฿** · คนขับได้ 189 ฿ · แพลตฟอร์มได้ 21 ฿
**ตัวอย่าง 2:** ขาย 300 กก. ห่าง 6 กม. → ยอดขาย 300 ฿ · ค่ารถตามสูตร 140 ฿ · เกษตรกรจ่าย 90 ฿ (30%) · กองทุนช่วยจ่าย 50 ฿ → **เกษตรกรได้สุทธิ 210 ฿** · คนขับได้ 126 ฿

## 7. ราคาตู้โดยประมาณ
ประมาณการจากราคาเครื่องจักรขนาดเล็กในตลาด (ยังไม่ได้ขอใบเสนอราคาจริง)

| รายการ | ประมาณ (บาท) |
|---|---|
| เครื่องสับ hammer mill ~3 kW + ตะแกรง | 25,000–40,000 |
| ชุดอัดเม็ด flat die + แม่พิมพ์ 2 ขนาด | 25,000–45,000 |
| ชุดอัดแท่ง screw press + ขดลวดความร้อน + ตัดท่อน | 40,000–80,000 |
| โครงตู้เหล็ก แผ่นปิด ช่องป้อน ถาด | 15,000–25,000 |
| ลิ้นสลับทาง + มอเตอร์ | 3,000–6,000 |
| ตู้ควบคุมไฟฟ้า (คอนโทรลเลอร์ รีเลย์ เบรกเกอร์ ปุ่มหยุดฉุกเฉิน) | 10,000–20,000 |
| หน้าจอสัมผัส + กล้อง + เครื่องสแกน QR | 5,000–10,000 |
| ตาชั่ง (load cell) + เซนเซอร์ความชื้น | 4,500–11,000 |
| พัดลมดูดฝุ่น + ถุงเก็บฝุ่น + แม่เหล็ก + อื่น ๆ | 7,000–13,000 |
| ค่าประกอบและทดสอบ | 15,000–30,000 |
| **รวมต่อตู้** | **≈ 150,000–280,000 บาท (กลาง ๆ ~2 แสน)** |

ยังไม่รวมสถานี (ลานตาก หลังคา โกดัง โซลาร์) ซึ่งแล้วแต่พื้นที่และงบหน่วยงานท้องถิ่น

**จุดคุ้มทุนคร่าว ๆ (ตัวอย่างเพื่ออธิบายเท่านั้น):** ถ้าตู้แปรรูป ~400 กก./วัน × 25 วัน = 10 ตัน/เดือน และได้กำไรสุทธิหลังหักค่าซื้อ ค่าไฟ ค่าแรง ~1.2 ฿/กก. → ~12,000 ฿/เดือน → **คืนทุนตู้ 2 แสนใน ~1.5 ปี** (ขึ้นกับราคาขายสินค้าจริง ต้องทดสอบ)

| ใคร | ได้อะไร |
|---|---|

| 🏛️ หน่วยงานท้องถิ่น | เครื่องมือลดการเผาที่วัดผลได้จริง (Dashboard) |
| 🌏 สิ่งแวดล้อม | ลดการปล่อยคาร์บอนและฝุ่น หมุนเวียนเศษพืชกลับเป็นปุ๋ย (SDG 3, 8, 12, 13) |

\* ค่าประมาณ ต้องอ้างอิงงานวิจัยก่อนใช้

**Triple Bottom Line:** People = รายได้เกษตรกรและคนขับ · Planet = PM2.5 ที่ลดได้ · Profit = ส่วนต่างราคาสินค้า + ค่าบริการ + ค่าแพลตฟอร์ม

| **12** Responsible consumption and production | เศษพืชเป็นอาหารสัตว์ เชื้อเพลิง ปุ๋ย ไม่มีอะไรเสียเปล่า (circular economy) |
| **13** Climate action | ลดคาร์บอนและฝุ่นจากการเผาในที่โล่ง วัดผลได้บน Dashboard |
| *เสริม* 7 · 15 | แท่งเชื้อเพลิงชีวมวล + หลังคาโซลาร์ · ลดไฟลามป่า เศษพืชกลับเป็นปุ๋ยบำรุงดิน |

## 9. ระบบซอฟต์แวร์ (ต้นแบบที่ใช้ได้จริง)
- **LINE OA + LIFF**: ดูราคา คำนวณรายได้ แจ้งขาย เรียกรถ รับ QR และใบรับของ ใช้สิทธิ์ PDPA (ถอนความยินยอมและลบข้อมูลได้)
- **หน้าคนขับ** `/liff/driver`: รับแจ้งงานใหม่ กดรับงาน นำทาง ดูรายได้
- **หน้าจอตู้** `/kiosk`: สแกน QR เลือกโหมด จำลองการแปรรูป
- **Dashboard** `/dashboard`: กก. ที่ไม่ถูกเผา, PM2.5, รายได้เกษตรกร, เงินที่กองทุนจ่ายค่ารถ, สถานะตู้
- **Present** `/present`: โมเดล 3D ของตู้ กดดูชิ้นส่วนแต่ละจุดได้ (ใช้บนจอหน้าบูธ)
- เทคโนโลยี: React + Vite, Vercel Functions, LINE Messaging API, Upstash Redis · ค่าใช้จ่าย 0 บาท/เดือนในช่วงต้นแบบ

## 10. ความเสี่ยงและแผนรับมือ
| ความเสี่ยง | แผน |
|---|---|
| ตัวเลขยังเป็นค่าประมาณ | ทดสอบกับเครื่องจริง แล้วแก้ในไฟล์เดียว `rules.js` |
| กฎหมายอาหารสัตว์ | ช่วงแรกใช้ในฟาร์มชุมชน แล้วค่อยขึ้นทะเบียนเมื่อขยาย |
| เครื่องสับเสียแล้วทั้งตู้หยุด | ใบมีดสำรอง + แจ้งช่างอัตโนมัติ |
| กองทุนค่ารถจ่ายเยอะในงานเล็ก | เรียกรถได้เมื่อ ≥ 300 กก./เต็มคัน · แนะนำให้รวมเที่ยวกับไร่ใกล้เคียง |
| ความปลอดภัยของคนขับ/น้ำหนักบรรทุก | กำหนดพิกัดรถ ประกัน และระบบคะแนนคนขับ (อนาคต) |
| เศษพืชเปียก | ไม่รับเกิน 20% · มีลานตากที่สถานี |
